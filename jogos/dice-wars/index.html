Velocidade da CPU

Cada jogador começa com o mesmo número de territórios e de dados. A ordem dos turnos é sorteada.

Como jogar

  1. Você é o verde-água. A pilha de dados em cada território é a força de ataque dele (máx. 8).
  2. Toque num território seu com 2 ou mais dados e depois num vizinho inimigo.
  3. Os dois lados rolam todos os dados. Se a soma do ataque for maior, você conquista: os dados passam para o território novo e fica 1 no de origem. Empate ou derrota: o atacante fica com 1 dado.
  4. Ao encerrar o turno, você recebe dados iguais ao seu maior bloco de territórios conectados (número no seu chip), espalhados ao acaso. Sobras ficam guardadas.
  5. Vence quem dominar o mapa inteiro.
